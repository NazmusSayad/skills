---
name: decide
description: Guides how to make better decisions. Use this skill before creating, refining, or finalizing a plan, making an important decision, or starting a big or long task.
---

Keep the decision aligned with the user's request and intent. Find facts yourself instead of asking the user. Ask independent questions together. Use the user's answers to update later questions, and wait before asking questions that depend on them.

Ask the user for choices or clarification when they materially affect the outcome. Use the question tool when available. Do not present alternatives when the user's request already determines the choice.

Resolve all assumptions, guesses, open questions, and remaining choices with the user before finalizing the decision.
